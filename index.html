YAMLで構造、Pythonでロジック 小さなツール / ミニアプリ向け

「ちょっとしたツール」を、SKIPで軽く組み立てる。

SKIPは、画面や構造をYAMLで定義し、ロジックをPythonで書くミニアプリフレームワークです。
フルスタックなGUIフレームワークほど重くなく、CLIだけよりも少しだけリッチな体験を目指しています。

SKIPのイメージ（YAML + Python）
window:
  title: "HELLO, SKIP!"
  width: 400
  height: 200

layout:
  - type: label
    id: message
    text: "HELLO, SKIP!"

  - type: button
    text: "Click"
    on_click: on_click_hello
def on_click_hello(ctx):
    # ctx は画面コンテキスト
    ctx["message"].text = "Button clicked!"

register_handler("on_click_hello", on_click_hello)
SKIPとは
YAMLで構造を、Pythonでロジックを記述するミニアプリフレームワーク
YAMLで宣言的に構造を書く
画面やレイアウト、コンポーネントの構造をYAMLで定義します。コードの見通しがよく、後から読み返しても理解しやすい形を目指しています。
ロジックはPythonに集中
イベントハンドラや処理はPythonで記述。YAMLからハンドラ名を紐づけることで、構造とロジックを自然に分離できます。
「ミニアプリ」にフォーカス
大規模アプリではなく、自分用ツールやチーム内ユーティリティなど、小さなアプリケーションを素早く作ることに特化しています。 
- 日常のちょっとした計算ツール
- テキスト変換・整形ツール
- APIクライアントの簡易フロント
- チーム内で共有する小さな業務支援ツール
YAMLベース Pythonロジック ミニアプリ 個人開発
YAML + Python の簡単な例
構造とロジックを分けて書くイメージ
window:
  title: "Tax Calculator"
  width: 480
  height: 260

layout:
  - type: input
    id: price_input
    label: "Price (JPY)"

  - type: input
    id: tax_input
    label: "Tax (%)"

  - type: button
    text: "Calculate"
    on_click: on_calculate

  - type: label
    id: result
    text: "Result will be shown here."
def on_calculate(ctx):
    price_str = ctx["price_input"].value
    tax_str = ctx["tax_input"].value

    try:
        price = float(price_str)
        tax = float(tax_str)
    except ValueError:
        ctx["result"].text = "Invalid input."
        return

    total = price * (1 + tax / 100.0)
    ctx["result"].text = f"Total: {total:.2f} JPY"
ミニIDE（println / var だけの小さなランタイム）
SKIPの「軽く試せる」感じを伝えるための、超シンプルなミニ言語
コードエディタ サポート: var name = value, println expr
簡易インタプリタです。SKIP本体とは別実装ですが、軽く試す雰囲気をイメージできます。
