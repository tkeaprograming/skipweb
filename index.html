SKIP
MINIMAL SCRIPT FRAMEWORK
概要 ミニIDE リンク Zenn
println と var から始める 小さなスクリプト / ツール向け

余計なものを全部スキップして、書きたいことだけ書く。

SKIPは、「ちょっと試したい」「小さな処理を書きたい」というときに、
余計なボイラープレートをできるだけ減らすことを目指したミニマルなフレームワークです。
まずは var と println だけの小さな世界から始められます。

ZennでSKIPの記事を読む
このページのミニIDEは、SKIPのごく一部のイメージ（println / var）だけを切り出した簡易版です。
SKIPのごく小さな断片
var name = "SKIP"
var x = 1
var y = 2

println name
println x
println x + y
println "HELLO, " + name
SKIPとは
「とりあえず書いて動かす」を軽くするためのミニマルな土台
小さなスクリプトにちょうどいい
ちょっとした計算、テキスト処理、ログ出力など、「ファイル1つで済む」ような用途を想定しています。
構文はできるだけシンプルに
まずは var と println のような、直感的で覚えやすい構文から始められます。
実験と学習のための場
新しいアイデアや構文を試すための「実験場」としても使えるように設計しています。 
- ちょっとした計算スクリプト
- テキストの整形や変換
- ログ出力のフォーマット実験
- 言語設計の試行錯誤
