YAMLベースのスクリプトエンジン 軽量 / 直感的 / 拡張しやすい

コードじゃなくて、YAMLで書くスクリプトという選択肢。

Skip は、YAMLで書ける軽量なスクリプトエンジンです。
Python を土台に、println や var などの直感的なコマンドで、
CLIツールやテキストベースの処理、ちょっとしたアドベンチャーまで組み立てられます。

GitHub: Skip-v0.1 を見る
このページのミニIDEは、Skip-v0.1 のごく一部（println / var）だけを再現した簡易ランタイムです。
demo.skp のイメージ（抜粋）
def:
  name: "greet"
  do:
    - println: " {C.Y}-------------------- {C.END}"
    - println: " Hello, {name}!"
    - println: " {C.Y}-------------------- {C.END}"

var: { name: "Explorer" }

call: "greet"

clc: "10 * 5 + 5"
println: " {C.G}Calculation Result: {res} {C.END}"
Skipとは
YAMLで書ける軽量スクリプトエンジン（Skip-v0.1）
YAML-Native
ロジックをそのままYAMLで書けるように設計されたスクリプトエンジンです。インデントとキーで構造が見えるので、後から読んでも追いやすいのが特徴です。
動的評価と変数展開
{var_name} のような形で、文字列中に変数を埋め込めます（f-string風）。計算結果や状態をそのままメッセージに反映できます。
軽量で拡張しやすい
Python製のエンジンなので、必要に応じてコマンドを追加したり、独自の処理を組み込んだりといった拡張がしやすい構造になっています。 
主なコマンド（Skip-v0.1）:
- println: コンソール出力
- typetext: タイピング風出力
- var: 変数の定義・更新
- clc: 数式の評価
- def: 関数定義
- call: 関数呼び出し
- adopt: 他の .skp を読み込み
- save: 変数の保存
- input: 入力の取得
- exit: スクリプト終了
