YAMLで画面、Pythonでロジック ミニアプリ / ツール開発向け

小さなツールを、YAML × Pythonで一瞬で形にする。

SKIPは、画面構成をYAMLで、ロジックをPythonで書くミニアプリフレームワークです。
「ちょっとしたツール」を作るときに、GUIフレームワークの細かいコードと格闘する必要はもうありません。

GitHubで見る
ローカル版のSKIP IDE（Python GUI）と組み合わせることで、YAMLファイルからそのままアプリを起動できます。
SKIPのイメージ
YAML → 画面 / Python → ロジック
YAML: 画面定義
window:
  title: "HELLO, SKIP!"
  width: 400
  height: 200

layout:
  - type: label
    id: message
    text: "HELLO, SKIP!"
    align: center

  - type: button
    text: "Click me"
    on_click: on_click_hello
Python: ロジック
def on_click_hello(ctx):
    # ctx は画面コンテキスト
    ctx["message"].text = "Button clicked!"

# SKIPランタイムに登録
register_handler("on_click_hello", on_click_hello)
SKIPの特徴
「小さなアプリ」を作るときにちょうどいい設計
YAMLで画面を宣言的に定義
ボタン、ラベル、入力欄などをYAMLで記述するだけで、画面が自動的に構築されます。 GUIフレームワークの細かいコードを書く必要はありません。
ロジックはPythonに集中
イベントハンドラや処理はPythonで記述。YAMLからハンドラ名を紐づけるだけで、画面とロジックが自然に分離されます。
「ミニアプリ」に最適化
大規模アプリではなく、「自分用ツール」「チーム内ユーティリティ」「ちょっとしたGUIフロント」を素早く作ることにフォーカスしています。
SKIPで作れるものの例
- 日常のちょっとした計算ツール
- APIクライアントの簡易GUI
- テキスト変換・整形ツール
- チーム内で使う小さな業務支援ツール
- 学習用のインタラクティブなサンプルアプリ

もう少し複雑な例
入力フォーム + 計算ロジックの組み合わせ
YAML: シンプルな計算ツール
window:
  title: "Tax Calculator"
  width: 480
  height: 260

layout:
  - type: label
    text: "Price (JPY)"
  - type: input
    id: price_input
    placeholder: "e.g. 1000"

  - type: label
    text: "Tax (%)"
  - type: input
    id: tax_input
    placeholder: "e.g. 10"

  - type: button
    text: "Calculate"
    on_click: on_calculate_tax

  - type: label
    id: result
    text: "Result will be shown here."
Python: 計算ロジック
def on_calculate_tax(ctx):
    price_str = ctx["price_input"].value
    tax_str = ctx["tax_input"].value

    try:
        price = float(price_str)
        tax = float(tax_str)
    except ValueError:
        ctx["result"].text = "Invalid input."
        return

    total = price * (1 + tax / 100.0)
    ctx["result"].text = f"Total: {total:.2f} JPY"

register_handler("on_calculate_tax", on_calculate_tax)
